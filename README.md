# Desafios em Engenharia de Software 🚀

Repositório dedicado ao registro, análise arquitetural e documentação de desafios reais de engenharia de software de nível pleno/sênior.

Cada desafio é estruturado no modelo **STAR** (*Situation, Task, Action, Result*), acompanhado de diagramas de arquitetura, trade-offs técnicos e lições aprendidas.

## 🎯 Padrão de Documentação dos Desafios
Cada pasta de desafio (`desafio-xxx`) contém:
- **`README.md`**: Detalhamento do desafio no formato STAR + Análise de Trade-offs.
- **`diagrama.md`**: Diagramas em Mermaid ilustrando o antes/depois, componentes e sequência temporal.
